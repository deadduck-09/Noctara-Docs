# 🌙 Noctara Docs

Official documentation for **Noctara-dots**.

This repository contains the documentation website, guides, configuration explanations, customization notes, and resources for the Noctara desktop setup.

## 🚀 Development

Clone the repository:

```bash
git clone https://github.com/deadduck-09/Noctara-Docs.git
cd Noctara-Docs
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run docs:dev
```

Build for production:

```bash
npm run docs:build
```

## 📚 About Noctara

Noctara-dots is a Linux desktop customization project focused on creating a beautiful, functional, and customizable Wayland experience.
