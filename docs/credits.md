# Credits

Noctara Dots is built on top of some incredible open-source projects.

A huge thank you to all the developers and maintainers who dedicate countless hours to building software that the Linux community can enjoy. This project simply brings many of those amazing tools together into one cohesive desktop experience.

---

# Core Projects

<div class="grid cards">

- **🌙 [Noctalia](https://github.com/noctalia-dev/noctalia)**

  The shell that powers the entire desktop experience.

- **🪟 [Niri](https://github.com/YaLTeR/niri)**

  Scrollable tiling window manager.

- **💠 [Hyprland](https://github.com/hyprwm/Hyprland)**

  Dynamic Wayland compositor.

- **🥭 [MangoWM](https://github.com/DreamMaoMao/Mango)**

  Additional Wayland window manager support.

</div>

# Applications

<div class="grid cards">

- **🖥️ [Kitty](https://github.com/kovidgoyal/kitty)**

  My editor of choice.

- **⚡ [Fastfetch](https://github.com/fastfetch-cli/fastfetch)**

  Beautiful system information.

- **🎵 [MPD](https://github.com/MusicPlayerDaemon/MPD)**

  Music daemon.

  Terminal file manager.

- **📊 [Waybar](https://github.com/Alexays/Waybar)**

  Cross-shell prompt.
